 FAILED PIN FLOW ===================>>

Insert Card
     ↓
Enter PIN
     ↓
Incorrect PIN?
     ↓
Retry Count < 3
     ↓
Try Again

OR

Retry Count == 3
     ↓
Retain Card
     ↓
Go to Idle State    



WITHDRAW FLOW =============+>>

User selects Withdraw
        ↓
Enter Amount
        ↓
Check Account Balance
        ↓
Check ATM Cash
        ↓
Deduct Account Balance
        ↓
Dispense Cash
        ↓
Print Receipt
        ↓
Return Card


CHECK BALANCE FLOW ===============+>>

User selects Balance Inquiry
        ↓
Fetch Account Balance
        ↓
Display Balance
        ↓
Return Card




1. ATM is the central controller.

2. ATM delegates behavior to ATMState.

3. Each state controls allowed operations.

4. Card is linked to BankAccount.

5. CashInventory manages ATM cash.

6. State transitions occur after each operation.
